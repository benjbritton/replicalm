# Archive

Local renders and experiments. **Nothing in this directory is tracked** except
this file — these are derived rasters measured in gigabytes, and every one of
them can be regenerated from the tracked code and the recorded parameters.

They are kept on disk because they are the evidence behind the figures and the
numbers quoted in `docs/`, and because the comparison images were cut from them.
The figures themselves *are* tracked, in `docs/figures/`, so a clone carries the
full visual evidence at about 2.9 MB without the 3.4 GB behind it.

## What exists locally

| directory | configuration | status |
|---|---|---|
| `render/` | CSF rigidness 2, one pass, noise filters off, 14.4 m radius | **superseded.** The flat-calibrated configuration — the center panel of every three-way comparison figure, and the one showing bead artifacts on mound flanks. |
| `render_r15/` | as above but a 1.5 m search radius | **superseded, and instructive.** Its apparent improvement was a scoring artifact: cells it could not solve were dropped rather than counted, so the steep ground left the denominator. |
| `render_smrf/` | SMRF one pass, 5 m radius, filters off | **superseded.** The intermediate step that fixed the flanks but not the terracing. Also holds `trench/` and `flank/`, the windowed sweeps. |
| `render_ncalm/` | the locked baseline | **current.** The accepted product: DEM, the six RVT layers including G1, and the comparison crops. |
| `../tests/` | — | working intermediates for the benchmark harness: clipped clouds, per-arm classifications, scratch rasters. Roughly 5.3 GB, regenerated by any harness run. |

Three of these sit at the repository root rather than inside `archive/` because
they were held open by another process when the move was made. They are ignored
either way — `.gitignore` covers both `render*/` and `archive/*`.

## Regenerating any of them

All commands run from `benchmarks/`, with `REPLICALM_DATA` pointing at the
G-LiHT products (see `paths.py`).

```bash
# a full tile at the locked baseline: classification, kriging, mosaic
#   argument 1 is the search radius, argument 2 a suffix for the output directory
python render_tile.py 20.0 _ncalm          # -> ../render_ncalm/dem/

# fill enclosed holes, trim the one-sided fringe, apply the mask convention
python finalise_render.py 20.0             # -> ../render_ncalm/dem_final/

# the G1 composite and the five RVT layers, from the finalised DEM
#   (needs the g1 conda environment, which has rvt-py)
python GLiHT_rvt.py --res 0p5m --no-metadata --workers 1 \
    --dem-root ../render_ncalm/dem_final --rvt-root ../render_ncalm/rvt
```

Reproducing the earlier configurations means editing the classifier block in
`render_tile.py`; the settings each one used are in the table above, and the
reasoning behind each change is in `docs/open_observations.md`.

For the windowed experiments behind individual figures:

```bash
python flank_classify.py     # CSF vs SMRF ground retention on a steep window
python trench_sweep.py       # SMRF working grid and threshold against terracing
python ncalm_faithful.py     # the source's parameters, verbatim and adjusted
python filters_relief.py     # noise filters isolated, on windows with relief
python recalibrate.py        # the eight-tile harness on relief-selected windows
```

Each writes its measurements as JSON. The committed copies are in
`benchmarks/results/`, with paths tokenized so they resolve anywhere.

## Why not Git LFS

At roughly 3.4 GB of intermediates that are fully reproducible from tracked
code, LFS would add bandwidth, storage quota and a required client install for
everyone cloning the repository, in exchange for artifacts they can regenerate
or, more usually, do not want. The figures that carry the argument are small and
tracked directly. If a specific render ever needs to travel, it is better sent
on its own than carried by every clone forever.
